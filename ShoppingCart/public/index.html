Shopping cart management

A small cart, with a lot to demonstrate.

This project runs two independent servers: a native Node.js HTTP server on port 3000 and an Express REST API on port 4000. Cart data is stored in memory.

Native HTTP server

Built with Node's http and fs modules. This page is served from public/index.html.

Express REST API

Start the second server on port 4000, then use EchoAPI or curl to manage products.
